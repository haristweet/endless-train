# ENDLESS TRAIN

列車の車窓を延々と眺めるアプリ。そのまま MP4 に書き出せる。
[ENDLESS DUNGEON](https://haristweet.github.io/endless-dungeon/)・[ENDLESS FLIGHT](https://haristweet.github.io/endless-flight/)・[ENDLESS WALK](https://haristweet.github.io/endless-walk/)・[ENDLESS DRIVE](https://haristweet.github.io/endless-drive/) の姉妹作で、書き出し・音・歌詞の仕組みは共通。
`index.html` と同梱の `mp4-muxer.js`・`opus-decoder.min.js` だけで動く（ビルド不要）。

## できること

- 右の窓ぎわの席から、横に流れる景色を眺める（窓枠・巻き上げた日よけ・窓台。夜は窓に車内が少し映る。レールの継ぎ目で小さく揺れる）
- 沿線5種を順に巡る（選んだものだけ。2分ごとなどで暗転して「2つ目の区間」と出る）
  - 郊外の街：線路ぎわの柵と道、家並み、マンション、遠くのビル
  - 田園地帯：田んぼ、電柱と電線、農家と木立、ときどき踏切の向こうへのびる道、遠くの山
  - 山あいの渓谷：斜面と針葉樹、ときどきトンネル（オレンジの灯り）と鉄橋（トラスが流れ、下に川）
  - 海沿いの線路：岩の浜と松、海に浮かぶ松の島、船
  - 雪国：雪原、雪をかぶった家と針葉樹、白い山、降る雪
- 街・田園・雪国では、ときどき駅を通過する（ホーム・屋根・人・駅名標・駅舎）。「まもなく ○○を 通過します」と案内が出る
- 隣の線路を、ときどき列車がすれ違う（夜は窓が灯る）
- 時刻がゆっくり移り変わる（朝→昼→夕方→夜）。一日の長さ：4分 / 8分 / 16分、走り始める時刻：朝・昼・夕方・夜
- 描き方：ポリゴン / 線画、画素の粗さ、速さ（各駅停車 54km/h・快速 90km/h・特急 144km/h）、路線の番号（シード）
- 画面の飾り（あり：速度計と運行の表示〈時刻・次の駅・区間・距離〉、路線図〈前の駅・次の駅・その次の駅といまの位置〉、車内欄〈案内と歌詞〉）
- MP4書き出し：640×480〜1920×1080、「3:19」のような長さ指定、30 / 60コマ/秒、音と歌詞（車内欄か字幕に流す）
- 終わり方：曲を入れて「BAD END にする」にチェックを入れると、終わりの3秒前に非常ブレーキがかかって景色の流れが遅くなり、終わりの2.6秒前に脱線して車体が横倒しになる。窓ガラスが割れ、暗転して「BAD END／列車は 二度と 駅に 着かなかった」

## しくみのメモ

- **線路と景色**：線路はまっすぐ z の負の向き。車窓は右（+x）を見るので、景色は右側にだけ作る。長さ30mごとの区切りを、番号・区間・区切りの番号から決まる乱数でその場で組み立てる。手前（架線柱・隣の線路）は速く、遠く（山）はゆっくり流れる。
- **トンネル・鉄橋・駅**：`Region.feat(i)` が12区切りごとにトンネル（5区切り）・鉄橋（2区切り）を決め、駅は40区切りごとに4区切り（`staAt`）。駅名は `STATIONS` から番号で選ぶ。
- **すれ違う列車**：`Sim.pass`。前の遠くに出て、隣の線路をこちらへ走ってくる。一両ずつ同じ形を並べて描く。
- **バッドエンド**：`Sim.speedAt()` で3秒前から速さを落とし、脱線したら止める。描画で視点を横に1.15ラジアンまで倒して下げる（`fall`）。窓ガラスのひび（`drawCracks`）。音（非常ブレーキのきしみ・脱線の衝撃・ガラス）は `crashSfx()` で作り、書き出しでは曲の上に重ねる。終わりの8秒前より後には区間を変えない。
- **描画・書き出し・音・歌詞**：ENDLESS WALK・DRIVE と同じ。
- ローカル確認：`python3 -m http.server 8803`
- 時刻のひとことの試験：`node test/msgs.mjs`（0 秒のコマでまとめて出ないこと・一日で順に一度ずつ出ること）
- 絵の確認：サーバーを立てて `node test/shots.mjs 出力.png`（沿線ごとに昼と夜を並べる）。BAD END を見るときは `TIMES=13,14.5,16.2,17.3,17.6,18,18.8,19.6 ROWS='[["city","solid",false,"noon",true]]'` のように時刻と［沿線・描き方・飾り・走り始め・BAD END］を渡す
